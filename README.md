# Parcel Permit Scout

A free, read-only Chrome extension that checks the building permits and inspections of every lot in your spreadsheet on county and town permit websites, and tells you which lots have nothing on record. Press "Try it on real lots" in the extension to see a real run and the two files it makes before you use your own lots.

- **Install:** [Chrome Web Store](https://chromewebstore.google.com/detail/imjobmedkffhnebdkklgjccndaiacgoi)
- **Website:** https://lisle2002.github.io/Parcel-Permit-Scout/
- **Report a problem or request your county or town:** [Issues](https://github.com/Lisle2002/Parcel-Permit-Scout/issues/new/choose)
- **Privacy policy:** https://lisle2002.github.io/Parcel-Permit-Scout/privacy.html
