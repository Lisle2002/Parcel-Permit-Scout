# Parcel Permit Scout

A free, read-only Chrome extension that checks the building permits and inspections of every lot in your spreadsheet on county permit websites, and tells you which lots have nothing on record.

- **Install:** [Chrome Web Store](https://chromewebstore.google.com/detail/imjobmedkffhnebdkklgjccndaiacgoi)
- **Website:** https://lisle2002.github.io/Parcel-Permit-Scout/
- **Report a problem or request a county:** [Issues](https://github.com/Lisle2002/Parcel-Permit-Scout/issues/new/choose)
- **Privacy policy:** https://lisle2002.github.io/Parcel-Permit-Scout/privacy.html

This repository holds the website and the issue tracker. The extension itself is distributed through the Chrome Web Store.
